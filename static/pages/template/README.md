# 需要的图片资源

请准备以下图片并放在此目录：

1. **template-preview.png** - 创作模板卡片左侧的预览图（建议尺寸：400x400px）
2. **create-icon.png** - 创作模板卡片右侧的图标（建议尺寸：320x320px，可以是相机/画框图标）
3. **avatar1.png** - 用户头像1（96x96px）
4. **avatar2.png** - 用户头像2（96x96px）
5. **avatar3.png** - 用户头像3（96x96px）
6. **avatar-more.png** - 更多用户头像占位（96x96px，可以是"..."或"+N"）

## 临时方案

如果暂时没有图片，可以：
- 使用网络图片URL
- 或者隐藏这些图片元素
- 或者使用纯色占位
