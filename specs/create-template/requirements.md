# 创作模板功能需求文档

## 介绍

本需求旨在为数字文旅小程序增加用户创作模板功能,允许普通用户创建个性化的照片模板并分享。创建的模板需经过管理员审核通过后才能在模板列表中展示,其他用户可基于该模板上传照片集。

## 业务背景

目前系统仅有3个官方模板(敦煌莫高窟主题、江南水乡风光、都市夜景打卡),用户无法创建自己的模板。为了丰富平台内容生态,需要开放用户创作模板的能力。

## 需求

### 需求1 - 创作模板入口

**用户故事:** 作为一名用户,我想要在模板列表页面点击"创作模板"按钮,以便开始创建我的个性化模板。

#### 验收标准

1. 当用户点击模板列表页的"创作模板"按钮时,小程序应跳转至创作模板页面(/pages/create-template/create-template)。
2. 跳转动画应使用右侧滑入效果(wx.navigateTo)。
3. 当用户未登录时,小程序应先引导用户完成登录,然后再跳转至创作模板页面。

### 需求2 - 模板信息填写

**用户故事:** 作为一名创作者,我想要填写模板的基本信息(名称、描述、分类、封面图),以便完整描述我的模板创意。

#### 验收标准

1. 当用户进入创作模板页面时,小程序应展示包含以下字段的表单:
   - 模板名称(必填,1-20字符)
   - 模板描述(必填,10-200字符)
   - 模板分类(必选,单选:景区主题/风格分类/场景打卡)
   - 模板封面图(必填,支持拍照或从相册选择)
   - 自定义标签(选填,最多3个,每个标签2-6字符)
   - 是否允许其他用户上传照片集(必选,默认为"是")

2. 当用户未填写必填项时,小程序应在对应字段下方显示红色提示文字。

3. 当用户填写的内容超出字符限制时,小程序应阻止继续输入并显示当前字符数/最大字符数。

4. 当用户点击上传封面图时,小程序应调用wx.chooseImage,支持从相册选择或拍照,最多选择1张图片。

5. 当用户选择的图片大小超过5MB时,小程序应显示提示"图片过大,请选择5MB以内的图片",并不允许上传。

### 需求3 - 封面图上传

**用户故事:** 作为一名创作者,我想要上传模板封面图到云存储,以便永久保存并在模板列表中展示。

#### 验收标准

1. 当用户选择封面图后,小程序应立即将图片上传至CloudBase云存储的templates文件夹。

2. 上传过程中,小程序应显示加载提示"上传中...",并展示上传进度。

3. 当上传成功时,小程序应在页面上显示已上传图片的预览,并存储cloudID用于后续提交。

4. 当上传失败时,小程序应显示错误提示"上传失败,请重试",并允许用户重新选择图片。

5. 当用户重新选择封面图时,小程序应删除之前上传的图片(避免云存储空间浪费)。

### 需求4 - 提交创作并审核

**用户故事:** 作为一名创作者,我想要提交我创建的模板,以便管理员审核后发布到平台。

#### 验收标准

1. 当用户填写完所有必填项并点击"提交创作"按钮时,小程序应将模板数据保存至CloudBase数据库的templates集合。

2. 新创建的模板记录应包含以下字段:
   - _id: 自动生成
   - _openid: 当前用户openid(自动添加)
   - name: 模板名称
   - description: 模板描述
   - category: 模板分类
   - cover: 封面图cloudID
   - tags: 自定义标签数组(如["文化", "历史"])
   - allowUserUpload: 是否允许上传(boolean)
   - isOfficial: false(用户创建的模板)
   - status: "pending"(待审核状态)
   - creatorId: 当前用户openid
   - creatorName: 当前用户昵称
   - photoSetCount: 0(初始照片集数量)
   - likeCount: 0(初始点赞数)
   - createTime: 当前时间戳
   - sort: 999(默认排序,审核通过后可调整)

3. 当提交成功时,小程序应显示成功提示"提交成功,等待审核",2秒后返回模板列表页。

4. 当提交失败时,小程序应显示错误提示并保留用户填写的内容,允许重新提交。

5. 提交过程中,小程序应禁用"提交创作"按钮,防止重复提交。

### 需求5 - 审核状态展示

**用户故事:** 作为一名创作者,我想要在"我的"页面查看我创建的模板及其审核状态,以便了解审核进度。

#### 验收标准

1. 当用户进入"我的"页面时,小程序应展示"我的模板"入口。

2. 当用户点击"我的模板"时,小程序应跳转至我的模板列表页(/pages/my-templates/my-templates)。

3. 该页面应查询当前用户创建的所有模板(通过_openid筛选),并按创建时间倒序排列。

4. 每个模板卡片应显示:
   - 封面图
   - 模板名称
   - 审核状态标签:
     - "待审核"(status=pending,橙色)
     - "已通过"(status=approved,绿色)
     - "未通过"(status=rejected,红色)
   - 创建时间
   - 照片集数量(审核通过后)

5. 当模板状态为"未通过"时,应显示审核意见(如果有)。

6. 当模板状态为"已通过"时,点击卡片应跳转至模板详情页。

### 需求6 - 管理员审核功能(后续迭代)

**用户故事:** 作为管理员,我需要在管理后台审核用户提交的模板,确保平台内容质量。

#### 验收标准(本期暂不实现,预留设计)

1. 管理员应能在CloudBase控制台或管理后台查看所有待审核模板。

2. 审核操作包括:
   - 通过: 将status改为"approved",模板出现在模板列表
   - 拒绝: 将status改为"rejected",填写拒绝理由

3. 审核通过的模板应自动出现在模板列表页,按sort字段排序。

## UI设计要求

根据现有模板列表页面的设计风格,创作模板页面应保持统一的视觉规范:

### 设计风格
- **主题色**: 紫色渐变 `linear-gradient(135deg, #667eea 0%, #764ba2 100%)`
- **强调色**: 橙红色 `#ff6b35`(用于按钮、重要标签)
- **背景色**: 浅灰 `#f5f5f5`
- **卡片背景**: 白色 `#fff`,圆角 `16rpx`,阴影 `0 4rpx 12rpx rgba(0, 0, 0, 0.05)`

### 页面结构
1. **自定义导航栏**: 沿用现有紫色渐变导航,左侧返回按钮,标题"创作模板"
2. **表单区域**: 白色卡片容器,包含所有输入字段,间距24rpx
3. **底部按钮**: 固定在底部的"提交创作"按钮,紫色渐变背景

### 组件规范
- 使用TDesign组件库(t-input、t-textarea、t-radio、t-image-upload等)
- 字段标签字体大小32rpx,颜色#333
- 输入框边框圆角12rpx,边框颜色#e5e5e5
- 必填标记使用红色星号

## 非功能性需求

1. **性能**: 封面图上传应在3秒内完成(正常网络环境)
2. **安全**: 数据库访问应配置安全规则,仅允许用户操作自己创建的模板
3. **兼容性**: 支持微信小程序基础库2.10.0及以上版本

## 约束条件

1. 用户必须登录后才能创作模板
2. 每个用户每天最多创建5个模板(防止刷量)
3. 封面图格式限制为jpg/png,大小限制5MB以内
4. 模板名称不能与已有模板重复(同名检查)

## 依赖关系

- 依赖CloudBase云开发环境(数据库、云存储、身份认证)
- 依赖TDesign小程序组件库
- 依赖现有的用户认证系统
